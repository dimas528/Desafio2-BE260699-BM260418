Proyecto 1
Juego del Ahorcado:
Es un juego en consola donde el usuario debe adivinar una palabra letra por letra. El sistema valida las letras ingresadas, muestra el progreso con guiones y controla los intentos hasta que el jugador gane o pierda.

Proyecto 2
Sistema de Registro de Notas:
Es un programa que permite ingresar estudiantes y sus notas, validando que estén entre 0 y 10. Luego calcula el promedio, la nota máxima y mínima, y muestra un reporte indicando si cada estudiante aprobó o reprobó.
