# Repositorio en GitHub con control de versiones
## ¿Qué deben investigar?
1 ¿Qué es Git y para qué sirve el control de versiones en proyectos de software?

es una herramienta de versionamiento de codigo hecha por linus Torvalds debido a que era poco practico mantener el kernel de linux, y los que existian no eran muy buenas o idiologicamente no gratos, por que tenian una aquitectura centralizada, asi que creo git, sirve para trabajar codigo de manera colaborativa y da muchas facilidades, tienes las verciones anterirores por si se arruina algo y es el estandar de la industria. 


2 Diferencia entre Git (herramienta local) y GitHub (plataforma en la nube).

git es la herramienta que desacar en tu pc para poder hacer los repositorios de manera "nativa" ya el github es el lugar donde podes mandar tus repos para colaborar o guardar el codigo.


3 Comandos básicos: git init, git add, git commit, git push, git pull, git clone.

git ini: inicializa un repo.

git add: agrega los cambios hechos.

git commit: permite hacer un comentario de los cambios hechos, es como un preproceso antes de hacer el push, commit significa algo como comprometerse.  

git push: envia o guarda los cambios de manera local o en la nube.

git pull: mediante este podemos traer los cambios a nuestro repo local

git clone: con este podemos clonar un repo


4 ¿Qué es un repositorio, un commit y una rama (branch)?

un repositorio es como un directorio(carpeta), pero en el cual se puede gestionar versiones, como que guarda los metadatos o los gestiona.  

un commit es un comentario que se hace para "comprometerse" a realir un cambio en el codigo.

una rama es una version del proyecto o una dependencia directa que se usa para no modificar la rama principal.


5 Cómo agregar colaboradores a un repositorio en GitHub.

creas el repo, entras a este y luego le te vas a configuraciones en el panel izquierdo, la primera opcion dice colaboradores, hay un boton que dice añadir personas, ahí pones el nombre del colaborador y de ahi le caera un correo y si lo acepta ya estaria.
